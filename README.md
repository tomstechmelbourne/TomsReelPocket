# Tom's Reel Pocket

*One of Tom's Tech Products — Focus On One Thing And Do It Well*

The phone companion of **Tom's Reel** (the Windows program that manages a collection of VHS tapes, cassettes,
CDs, VCDs, DVDs, Blu-rays, 4K UHD discs and vinyl).

Open **https://tomstechmelbourne.github.io/TomsReelPocket/** in Chrome on the phone and choose
⋮ → *Add to Home screen*. Pocket then works without internet.

- **Do I have it?** Search by name: accents optional, small typing slips forgiven, original or Vietnamese title. Shows which formats you have (and where: shelf / box and number) and which you do not.
- **Favourites ★**, **Wish list** with the most you want to pay, **I just bought it**.
- **Private:** this site holds only the app. The collection is loaded from a file you pick
  (`TomsReel-Pocket.json`) and stays in the phone's browser storage. Changes go back to Tom's Reel
  as a file you save (`TomsReel-Changes-….json`). Nothing is uploaded anywhere.
